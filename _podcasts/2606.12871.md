## Paper

**[DailyReport: An Open-ended Benchmark for Evaluating Search Agents on Daily Search Tasks](https://arxiv.org/abs/2606.12871)** — Jingxuan Han, Wei Liu, Mingyang Zhu et al.

## Summary Card

### Motivation
Existing benchmarks for Search Agents (SAs) focus on specialized, expert-crafted tasks that do not reflect real-world user information needs, and their coarse task-level rubrics limit evaluation interpretability. There is a need for a benchmark grounded in authentic, timely daily search scenarios to assess whether SAs can reliably satisfy practical user demands.

### Method
DailyReport introduces 150 open-ended daily search tasks derived from trending topics on social platforms, decomposed into subtasks with 3,546 cascade rubrics across three disentangled dimensions: instruction following, factuality, and rationality. A user-centric cascade evaluation pipeline applies performance attribution to compute interpretable dimensional scores and a user preference score by weighting subtask importance.

### Key Results
Evaluation of 17 agentic systems reveals that current SAs perform well on instruction following but struggle significantly with factuality and rationality. User preference scores are particularly low, indicating a clear gap between agent outputs and user expectations.

### Takeaways
DailyReport provides a realistic, interpretable, and continuously updatable benchmark for SA evaluation. The results highlight that improving factual accuracy and reasoning quality is critical for advancing SAs toward practical daily use, and the cascade rubric framework offers a template for more user-aligned evaluation in agentic systems.
